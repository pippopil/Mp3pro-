**MP3 Player Pro** — это бескомпромиссный современный аудиоплеер для Android на **Kotlin**, созданный с чистого листа на базе новейшего движка **Jetpack Media3 (ExoPlayer)** и **Jetpack Compose Material 3**. 

Проект полностью очищен от устаревшего легаси-кода 2018 года, рекламных библиотек Google AdMob, аналитических трекеров и тяжелых фреймворков.

---

## 🌟 В чём уникальность MP3 Player Pro (отличия от других плееров):

Большинство музыкальных плееров в Google Play выглядят одинаково: скучный серый список, стандартный кругляш с треугольником Play и плоский звук. В **MP3 Player Pro** реализованы функции, которых нет ни в одном типовом плеере:

### 1. 🐸 Анимированный маскот: «Dancing Frog Visualizer»
* На карточке играющего трека оживает забавный неоновый кибер-лягушонок.
* Он танцует, прыгает и покачивается в такт музыкального ритма, поднимая настроение во время прослушивания.
* Этот же персонаж лёг в основу фирменной адаптивной иконки приложения **«Audiophile Cyber Frog»**.

### 2. ⚡ Сабвуферный Bass Boost с динамической компенсацией хэдрума
* **Проблема обычных плееров:** при выкручивании ползунка басов громкость остальных частот резко падает и звук становится глухим («эффект подушки»).
* **Наше решение:** аудиодвижок подключается напрямую к аппаратному `AudioSessionID` через Media3 ExoPlayer, задействуя сабвуферный фильтр низких частот с предиктивным лимитером и динамическим хэдрумом. Бас становится плотным, глубоким и вибрирующим, а вокал и тарелки остаются кристально чистыми!

### 3. 💿 4 интерактивных стиля отображения обложки (включая реалистичный Винил)
* **💿 Винил (Vinyl 33⅓ RPM):** аналоговая пластинка с концентрическими звуковыми канавками, вращающимся тонармом со стилусом и **динамическими радиальными бликами света**, которые плавно скользят по поверхности при вращении со скоростью 33⅓ об/мин.
* **🪞 3D Стекло (Glassmorphism):** парящая стеклянная карточка с эффектом глубины и неоновой фаской.
* **✨ Неоновая Аура (Neon Aura):** пульсирующий ореол света, реагирующий на выбранный пресет эквалайзера.
* **🖼️ Постер (Poster View):** классическая минималистичная альбомная обложка от края до края.

### 4. 🎨 Генеративный движок «No-Empty-Covers» (Никаких пустых обложек!)
* Если у локального MP3 файла нет обложки в ID3-тегах, плеер выполняет каскадный поиск официального HD-арта (1000x1000) через Apple Music / iTunes API.
* Если трек редкий, диктофонный или авторский — плеер прямо на устройстве генерирует стильный процедурный арт с кибер-градиентом, звуковыми кольцами и инициалами трека. **У вас в медиатеке больше никогда не будет серых заглушек с нотами!**

### 5. 🌐 Глобальный онлайн-поиск и скачивание музыки в память телефона
* Быстрый поиск любых мировых и отечественных исполнителей (*Кино, Eminem, Linkin Park, Miyagi, Queen, Phonk* и др.).
* Возможность прослушать превью трека перед скачиванием.
* Потоковая загрузка аудиопотока в высоком качестве 320 kbps напрямую в папку `/Music/` с отображением реального прогресс-бара и мгновенным добавлением в библиотеку.

### 6. 🟡 Прямая синхронизация с Яндекс Музыкой по OAuth
* Подключение личного аккаунта Яндекс Музыки через безопасный персональный OAuth-токен.
* Выгрузка плейлистов, любимых треков и избранных альбомов без передачи пароля от аккаунта.

### 7. 🔀 Честный алгоритм Shuffle без повторов
* В отличие от простых плееров, где воспроизведение вперемешку часто запускает один и тот же трек по кругу, здесь используется честная перемешанная очередь: треки не повторяются, пока не проиграет весь список, а кнопка «Предыдущий» возвращает именно на предыдущий прослушанный трек.

### 8. 🛡️ 100% Privacy-First и нулевой вес
* **0 рекламы:** вырезаны все баннеры AdMob, межстраничные объявления и сбор телеметрии.
* **Target SDK 34 (Android 14/15):** поддержка Scoped Storage (`READ_MEDIA_AUDIO`), Edge-to-Edge и прогнозного жеста «Назад».
* **Мгновенный запуск:** никаких вылетов на Android 14/15, HyperOS и MIUI (исправлена циклическая перезагрузка ADB).

## 🚀 Как запустить и протестировать:

### Вариант 1. Скачать готовый APK (Рекомендуется)
Просто перейдите во вкладку [Releases](https://github.com/pippopil/Mp3pro-/releases) и скачайте свежий файл:
* **`MP3PlayerPro-vX.X.X-beta.apk`** — для быстрой установки на телефон (Poco, Xiaomi, Samsung, Pixel и др.).
* **`MP3PlayerPro-vX.X.X-beta.aab`** — для публикации в Google Play Console.

### Вариант 2. Сборка из исходников в Android Studio
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/pippopil/Mp3pro-.git
   ```
2. Откройте папку проекта в **Android Studio Hedgehog / Iguana / Koala / Ladybug (2024+)**.
3. Дождитесь завершения Gradle Sync (используется Gradle 8.7 и JDK 17).
4. Нажмите **Run ▶** (или выберите устройство POCO / эмулятор).

### Вариант 3. Автоматическая облачная сборка через GitHub Actions
Создайте новый тег версии и отправьте в репозиторий:
```bash
git tag -a v1.0.0-beta03 -m "Release v1.0.0-beta03"
git push origin v1.0.0-beta03
```
GitHub Actions автоматически соберёт подписанный Release APK и выложит его в раздел Releases!
